## 📚 教程目录

本教程包含6个完整的课程，从基础到实战，帮助你快速掌握Python编程。

### 第1课：基础语法
**文件：`01_基础语法.py`**
- 变量和数据类型（str, int, float, bool）
- 字符串操作和格式化
- 数字运算和数学函数
- 类型转换
- 输入输出
- 实用练习题

### 第2课：控制流程
**文件：`02_控制流程.py`**
- if-elif-else 条件语句
- 比较运算符和逻辑运算符
- for 循环和 while 循环
- break 和 continue
- 列表推导式
- 异常处理（try-except）
- 九九乘法表、质数判断等实战练习

### 第3课：函数和模块
**文件：`03_函数和模块.py`**
- 函数定义和参数
- 默认参数、可变参数、关键字参数
- Lambda 表达式（匿名函数）
- 变量作用域
- 常用内置函数（map, filter, zip等）
- 递归函数
- 文档字符串和类型提示

### 第4课：数据结构
**文件：`04_数据结构.py`**
- 列表（List）：创建、访问、修改、方法
- 元组（Tuple）：不可变序列
- 字典（Dictionary）：键值对、遍历、嵌套
- 集合（Set）：去重、集合运算
- 数据结构选择指南
- 实用练习：词频统计、矩阵转置等

### 第5课：面向对象编程
**文件：`05_面向对象编程.py`**
- 类和对象基础
- 类属性和实例属性
- 继承和多态
- 封装（私有属性和方法）
- 特殊方法（魔术方法）
- 类方法和静态方法
- 实战：学生类、图书管理系统

### 第6课：实战项目
**文件：`06_实战项目.py`**
- 项目1：待办事项管理器
- 项目2：简单计算器
- 项目3：学生成绩管理系统
- 项目4：猜数字游戏
- 项目5：文本分析器

## 🚀 如何使用本教程

### 方法1：按顺序学习（推荐）
```bash
# 在终端中依次运行每个文件
python3 01_基础语法.py
python3 02_控制流程.py
python3 03_函数和模块.py
python3 04_数据结构.py
python3 05_面向对象编程.py
python3 06_实战项目.py
```

### 方法2：在VS Code中运行
1. 打开任意 `.py` 文件
2. 点击右上角的运行按钮 ▶️
3. 或按 `Ctrl+Shift+P`（Mac: `Cmd+Shift+P`），输入 "Python: Run Python File"

### 方法3：交互式学习
```bash
# 打开Python交互式环境
python3

# 导入并运行某个模块
>>> exec(open('01_基础语法.py').read())
```

## 💡 学习建议

1. **动手实践**：不要只看代码，自己动手修改和运行
2. **做练习题**：每课末尾都有练习题，务必完成
3. **理解而非记忆**：理解概念比死记硬背更重要
4. **循序渐进**：按顺序学习，不要跳过基础课程
5. **多写代码**：编程是实践性技能，多练习才能熟练
